          03
          
Same budget, three geometries

          
Worlds hold about 256 cells in 2D, 3D, and 4D, and every trajectory is cut at six history lengths.

        

        

          

            
2D16 × 16 = 256 cells

            

            
Each cell has up to 4 axis neighbors.

          

          

            
3D6 × 6 × 7 = 252 cells

            

            
Up to 6 neighbors; most cells sit near a boundary.

          

          

            
4D4 × 4 × 4 × 4 = 256 cells

            

            
Up to 8 neighbors, shown as a 4 × 4 array of 2D slices.

          

        


        

          

            
Six prefixes, one trajectory

            
Each generated trajectory is cut at T = 0, 1, 8, 16, 32, and 64. Every prefix is a separate request with its own reference final state.

          

          
        


        

          

            

          

          

            
8 families × 3 dimensions × 8 trajectories × 6 prefixes

            
= 1,152 main instances from 192 trajectories

            
+ 336 instances from 56 trajectories in 7 additional 2D workload conditions

            

              
1,488 instances · 248 trajectories

              
× 6 models = 8,928 scored outcomes

            

          

        

      

    


    
    

      

        

          04
          
How six LLMs hold up

          
Same prompts, one answer each, no tools. Exact recovery falls quickly as histories grow longer.

        


        

          

            

              Exact match by history length on the main view
            

          

        

        
Correct complete states out of 192 main instances per history length (one per trajectory); the last column pools the 768 instances at T = 8–64. Models are listed in the study's fixed order. Bars show exact match within each column.


        

          

            
1

            

              
Similar single-event performance can lead to different long-history profiles.

              
Kimi K2.5 and MiniMax M2.5 solve more one-event instances than Claude 5 Sonnet (148 and 150 versus 137 of 192), yet by T = 8 Claude 5 Sonnet leads them 91 to 33 and 31.

            

          

          

            

              

                
                
                
              

              

            

            
          

          

          

          

          

        


        

          

            
2

            

              
Similar exact-match scores can conceal different spatial errors.

              
A final state can be wrong in a few cells or across much of the grid. On the same failed instances, models with near-identical exact match can differ several-fold in how many cells they get wrong.

            

          

          

            

              
Median wrong cells · valid incorrect predictions, main view

              

            

            

              
Shared instances at T = 8 · Kimi K2.5 33/192 vs. MiniMax M2.5 31/192 EM

              

            

          

          
Left: median wrong-cell count among valid incorrect answers at T = 1, 16, and 64; n beside each model counts those answers. Right: the 84 main instances where both Kimi K2.5 and MiniMax M2.5 return valid incorrect states at T = 8, on log scales. Medians 14 versus 67; Kimi K2.5 has fewer wrong cells on 68, equal on 3, and more on 13. These outcome-selected comparisons complement exact match on the full set.

        


        

          

            
3

            

              
An incorrect final state can still recover substantial spatial change.

              
At T = 64 almost every answer is wrong, but some models still place far more correct values than copying the initial world would.

Left: mean cell accuracy of each model's valid T = 64 answers (n of 192 shown), with copy-initial and all-zero baselines computed on the same subset. Neither baseline solves any of the 960 positive-length main instances. Right: wrong cells only among changed cells (C), only among preserved cells (U), or both. At T = 64 most failures combine both kinds.

No prefix imputation

            
Aggregate decline is not a per-trajectory threshold: a later prefix is sometimes solved after an earlier one fails, so each length is requested and scored independently.

          

          

            
Delivery is part of the score

            
Empty outcomes and length terminations remain in exact match. Their counts are recorded per model as distinct properties.

          

          

            
Verified references

            
An independent rule implementation replays selected states in both cohorts with zero mismatches.

          06
          
    Use Grid-Bench
    
          
    The simulator and scorer use only the Python standard library. Scoring saved answers needs no API key.
    
        
    
        
    
          
    
            
    Quickstart
    
            
    Run a small example and score the reference answer against a copy-initial baseline.
    

    git clone https://github.com/grid-bench/Grid-Bench.git
cd Grid-Bench
python -m pip install -e .
python scripts/quickstart.py
    
            
    GitHub soon
    
          
    
          
    
            
    Evaluate your model
    
            
    Send each instance's prompt to your model, save one response per line, and score them.
    

    grid-bench evaluate \
  --data Grid-Bench-data \
  --predictions answers.jsonl \
  --out evaluation
