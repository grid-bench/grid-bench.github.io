Grid-Bench

Can LLMs Predict How Discrete Worlds Change?

Eight families of spatial operations transform two-, three-, and four-dimensional grids. Given an initial world, explicit rules, and an event history, a language model predicts the complete final state. Grid-Bench makes every predicted cell checkable against executable reference rules.

See a world change

02 / Evaluation

          
Exact by construction

          
A reference simulator executes every event, so each instance has one correct final world. Scoring compares predictions coordinate by coordinate rather than judging free-form text.

        

        

          

            
STEP 1

            

            
Initial world

            
A bounded integer grid. Unlisted cells are zero, coordinates start at zero, and space never wraps.

          

          

            
STEP 2

            

            
Rule + event history

            
One operation family, interleaved with SET assignments. Histories hold 0, 1, 8, 16, 32, or 64 events.

          

          

            
STEP 3

            

            
Complete prediction

            
One response, no tools: every nonzero cell listed once as [coordinate, value].

          

          

            
STEP 4

            

            
Cell-level scoring

            
Exact match requires every coordinate to agree; cell-level diagnostics describe what is wrong and where.

          

        


        

          

            
Six prefixes, one trajectory

            
Each generated trajectory is cut at T = 0, 1, 8, 16, 32, and 64. Every prefix is a separate request with its own reference final state, so prefixes share an underlying history. Intervals therefore resample whole trajectories, not rows.

          

          
        


        

          

            
EM Exact match

            
One only when a valid complete state equals the reference at every coordinate. Empty, invalid, and length-terminated answers stay in the denominator as zero.

          

          

            
CA Cell accuracy

            
The fraction of all grid cells with the correct value, reported on the stated valid-answer subset, alongside the count of wrong cells.

          

          

            
C / U Changed & preserved cells

            
Errors are located on cells whose reference value changed from the initial world (C) or stayed the same (U), separating missed updates from corruption.

          

        

      

    


    
    

      

        

          
03 / Operations

          
Eight families of spatial operations

          
The families cover geometry, neighborhoods, connected regions, and movement. Each animation replays the first 24 events of a real 2D benchmark trajectory as executed by the reference simulator. Select a card for the exact rule and a worked example.

        

        

        
Changed cells are outlined at each step. support: whether the affected cells are selected by geometry or by the current state. update: relabel, transport, or aggregate. Every family also accepts SET(p,v).

Same cell budget, three geometries

          
Main-study worlds hold about 256 cells in every dimension. Moving from 2D to 4D changes neighborhoods, boundary exposure, coordinate arity, and the length of the text representation together.

    06 / Results
    
          
    What the study finds
    
          
    Six LLMs answer the same 1,488 instances with identical prompts: one answer per instance, no tools, a 128,000-token combined reasoning-and-answer ceiling. Exact recovery declines sharply with history length, and the content of wrong answers differs widely between models.
    
        
    

        
    
          
    
            
    
              Exact match by history length on the main view
            
    
          
    
        
    
        
    Correct complete states out of 192 main instances per history length (one per trajectory); the last column pools the 768 instances at T = 8–64. Models are listed in the study's fixed order. Bars show exact match within each column.
    

        
    
          
    
            
    1
    
            
    
              
    Similar single-event performance can lead to different long-history profiles.
    
              
    Kimi K2.5 and MiniMax M2.5 solve more one-event instances than Claude 5 Sonnet (148 and 150 versus 137 of 192), yet by T = 8 Claude 5 Sonnet leads them 91 to 33 and 31.
    
            
    
          
    
          
    
            
    
              
    
                
                
                
              
    
              
    
            
    
            
          
    
          
    
          
    
          
    
          
    
        
    

        
    
          
    
            
    2
    
            
    
              
    Similar exact-match scores can conceal different spatial errors.
    
              
    A final state can be wrong in a few cells or across much of the grid. On the same failed instances, models with near-identical exact match can differ several-fold in how many cells they get wrong.

    No prefix imputation
    
            
    Aggregate decline is not a per-trajectory threshold: a later prefix is sometimes solved after an earlier one fails, so each length is requested and scored independently.
    
          
    
          
    
            
    Delivery is part of the score
    
            
    Empty outcomes and length terminations remain in exact match. Their counts are recorded per model as distinct properties.
    
          
    
          
    
            
    Verified references
    
            
    An independent rule implementation replays selected states in both cohorts with zero mismatches.
    
          
    
        
    
      
    
    
    

    
    
    
      
    
        
    
          
    07 / Get started
    
          
    Run it offline in a minute
    
          
    The simulator and scorer use only the Python standard library. Neither the quickstart nor dataset loading needs an API key.
    
        
    
        
    
          
    
            
    Quickstart
    
            
    Execute a small example, render its formal prompt, and score the reference against copying the initial state.
    

    # Python 3.11+, no API key
pip install -e .
python scripts/quickstart.py
spatial-worlds simulate \
  examples/metric_paint.json
