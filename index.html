02

One change shapes the next

Spatial instructions describe how to move objects, transform regions, or change their surroundings. Applied in sequence, each one acts on a world that earlier ones have already changed.

From the paper’s Figure 1: the entity moves right, a SET adds an obstacle in its column (pink), and the next move, allowed two cells, stops after one (✕). Cyan is the entity (1), slate an obstacle (2), dark empty (0).

What we ask, and why

Instructions like these show up in tasks from object manipulation to geometric design, where an earlier change can alter what a later one does. Can a language model follow such a history and say exactly where everything ends up?

In Grid-Bench, the model reads the starting grid, the rules, and the events as text, and writes the complete final grid in one response. Eight operation families cover geometry, neighborhoods, connected regions, and movement, in 2D, 3D, and 4D. Histories run up to 64 events, which separates getting one operation right from keeping track of many.

The design

Grids make space explicit. Coordinates and adjacency are spelled out, so a reflection inside a box and the growth of a connected region share one representation and one answer format.

The answer is the whole world. Many spatial benchmarks check selected relations or entity states; here every cell must be right, including the many that should not change. Exact match asks for complete recovery; cell-level checks show how far a wrong answer is off, and where.

The rules execute. A simulator computes the exact final state for any history, so every prediction is checkable, and the same rules can supply training examples with exact targets.

Explicit rules do not make this easy. The best model we tested gets 95% of grids exactly right after one event, and 13% after 64.

    Six prefixes, one trajectory
    
            
    Every trajectory has 64 events and is cut at six lengths. Each cut is a separate request, scored against its own reference final state.
    
            The six prefixes of a trajectory share one history, so they are not independent rows. Confidence intervals therefore resample whole trajectories, not rows, keeping each trajectory's prefixes together.

    Beyond the leaderboard
    
          
    Where models pull apart as histories grow, how far their wrong grids miss, and what those grids still get right.
    
        
    


        
    
          
    
            1
            
    Close at one event, far apart by eight
    
            
    Kimi K2.5 and MiniMax M2.5 solve more one-event instances than Claude 5 Sonnet (148 and 150 vs. 137 of 192), yet at T = 8 Claude 5 Sonnet leads 91 to 33 and 31.

    Similar scores, different errors
    
            
    Kimi K2.5 and MiniMax M2.5 are nearly tied at T = 8 (33 vs. 31 of 192), yet on the 84 instances where both return a valid wrong grid, their median wrong cells are 14 and 67.
    
          
    
          
    
            
    
              
    
                
                
              
    
              
    
              
    
            
    
            
    
              
    
              
    
            
    
            
    
              
    
              
    
            
    
          
    
        
    

        
    
          
    
            3
            
    Wrong grids can still capture real change
    
            
    At T = 64, the six models miss the exact grid on 1,111 of their 1,152 attempts (192 each), yet GPT-5.6 Sol's valid answers still get 81.6% of cells right, against 51.0% for copying the initial world.

      git clone https://github.com/grid-bench/Grid-Bench.git
cd Grid-Bench
python -m pip install -e .
python scripts/quickstart.py
      
                
      Needs Python 3.11 or newer. Runs and scores a small example with no credentials or model calls.
      
              
      
              
      

      grid-bench evaluate \
  --data /path/to/Grid-Bench-data \
  --predictions answers.jsonl \
  --out evaluation
      
                
      Write answers.jsonl with one JSON line per response: {"public_id": "...", "response": "..."} 
      
                
      The default main view scores 1,152 instances; --view all scores all 1,488. Missing answers stay in the denominator.
